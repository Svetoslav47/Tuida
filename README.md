# Tuida

Website for Tuida, a residential development of houses in Bulgaria. Live at **[tuida.life](https://www.tuida.life)**.

The site shows the houses and their floor plans, an interactive site map, the location, construction progress, a photo and video gallery, and a contact form for buyers.

## Stack

React 19, TypeScript, Vite, Tailwind CSS and React Router, deployed on Vercel.

## Run locally

```bash
cd Tuida
npm install
npm run dev
```
